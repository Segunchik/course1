# course1
## Описание проекта
Проект представляет собой инструмент для анализа финансовых операций, включая расходы по категориям, 
инвестиционный анализ и формирование отчетов. Система позволяет фильтровать транзакции, получать курсы валют, 
цены акций и генерировать отчеты.
## Структура проекта
### Основные компоненты
#### utils.py: 
Содержит вспомогательные функции:
* `greeting_by_time_of_day`
* `get_first_day_of_month`  
* `load_user_settings`  
* `get_operation_for_period_from_excel`  
* `get_expenses_by_card`  
* `get_top5_transaction`  
* `get_currency_rate` 
* `get_stock_prices`
#### services.py: 
Реализует функцию простого поиска по описанию
#### reports.py:
Содержит функцию для анализа расходов по категориям и 
* `spending_by_category`
#### views.py:
Содержит функцию для отображения главной страницы
* `main_info`
